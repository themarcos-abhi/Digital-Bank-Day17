# IT Concepts Recap & Q&A

## Session Overview

This session consolidates the week's learning through structured review, collaborative discussion, and self-assessment activities, with an emphasis on the underlying technical concepts.

## Agenda

### 1. Review: Technology Fundamentals

Revisit core concepts covering computers, networks, and cloud computing, including:

* **Hardware components:** CPU, RAM, storage (HDD/SSD), motherboard, power supply
* **Operating systems:** Windows, macOS, Linux basics and file system structures
* **Networking basics:** IP addressing (IPv4/IPv6), subnetting, DNS, DHCP, default gateways
* **Network devices:** Routers, switches, firewalls, access points
* **Cloud computing models:** IaaS, PaaS, SaaS
* **Cloud deployment models:** Public, private, and hybrid cloud

### 2. Review: Business Applications and SaaS Concepts

Recap how Software as a Service (SaaS) and common business applications fit into organizational IT environments.

* **SaaS characteristics:** Subscription-based access, centralized hosting, automatic updates
* **Common business platforms:** Microsoft 365, Google Workspace, Salesforce, Slack
* **Identity and access management:** Single sign-on (SSO), multi-factor authentication (MFA), user provisioning/deprovisioning
* **Licensing models:** Per-user, per-device, tiered licensing
* **Data considerations:** Data residency, backup responsibility (shared responsibility model)

### 3. Review: IT Support Workflow and Troubleshooting Mindset

Reinforce the standard IT support workflow and the problem-solving approach used when troubleshooting issues.

* **Ticketing workflow:** Ticket creation, triage, prioritization, assignment, resolution, closure
* **Troubleshooting methodology:**
  1. Identify the problem
  2. Establish a theory of probable cause
  3. Test the theory
  4. Establish a plan of action
  5. Implement the solution
  6. Verify functionality
  7. Document findings
* **Escalation criteria:** When and how to escalate to Tier 2/3 support
* **Common diagnostic tools:** ping, nslookup/dig, tracert/traceroute, ipconfig/ip addr, Event Viewer, Task Manager

### 4. Group Q&A

Open forum to address any confusion or outstanding questions from the week's material, including technical clarifications on networking, cloud services, or troubleshooting steps.

### 5. Concept Mapping Exercise

Collaborative activity to visually map how different IT concepts connect, for example:

* How DNS resolution supports application access
* How SaaS platforms depend on underlying network and cloud infrastructure
* How the troubleshooting workflow applies across hardware, network, and application layers

### 6. Vocabulary Review

Flashcard activity to reinforce key technical terms, including:

* IP address, subnet mask, gateway, DNS, DHCP
* SaaS, PaaS, IaaS
* Ticket, escalation, SLA (Service Level Agreement)
* Bandwidth, latency, packet loss
* Authentication, authorization, encryption

### 7. Peer Teaching

Each group selects one technical concept (e.g., DNS resolution, cloud service models, or the troubleshooting workflow) and presents an explanation of it to the class, including a practical example or use case.

### 8. Confidence Check

Individual self-assessment to gauge comfort level and understanding of the technical concepts covered, including networking fundamentals, cloud/SaaS models, and troubleshooting methodology.

## Objective

By the end of this session, participants should have a consolidated technical understanding of the week's material, clarity on any previously confusing topics, and a self-assessed baseline of their confidence in core IT concepts.
